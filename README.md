# Pitch it, build it, secure it

In 50 minutes your team invents a product that **earns money**, **solves a real user problem**, and **takes security seriously**, including what happens if it runs on **critical infrastructure** such as water or energy. An AI chat agent guides you the whole way and builds a mockup of your idea. At the end you guess how many tokens you used.

> Student exercise, not affiliated with or endorsed by any company.

## Before you start

- A laptop with a browser.
- A GitHub account. Create one for free at <https://github.com/signup>. It takes 2 minutes.
- Any AI chat agent: ChatGPT, Claude, Gemini, Copilot or similar. The free tiers are fine.

## How it works — 3 steps

1. **Pick a driver.** One person types into the chat agent. Everyone else researches on their own laptops and feeds answers to the driver. Organise the rest however you like.
2. **Open [MASTER-PROMPT.md](MASTER-PROMPT.md)**, copy the whole box, and paste it into your chat agent.
3. **Follow the agent.** It's your coach, not your ghostwriter: **you** come up with the idea and the answers. The agent challenges you, then builds the mockup from your answers and helps you hand in a pull request to `teams/team-N/`.

Stuck? Type `HINT`. Out of time? Type `NEXT`.

## Timeline

| Min | Phase |
|---|---|
| 0–5 | Intro, pick a driver, paste the master prompt |
| 5–15 | Idea: lock one idea as a one-liner |
| 15–30 | Checklist: Problem, Money, Security, Critical infrastructure, AI cost |
| 30–35 | Mockup: you design the main screen, the agent builds `mockup.html` |
| 35–40 | Optional [Security Game](SECURITY-GAME.md) → paper token guess → `FINISH` → `summary.md` → pull request |
| 40–50 | 1-minute pitch per team |

Rules and scoring are in [RULES.md](RULES.md).
